# Band Bots identity

Use **Band Bots** as the display name. The repository and technical identifiers remain `BAND_BOTS`.

Existing database filenames, browser storage keys, session signatures, and cloud-computer ownership labels keep their earlier `band-slack` identifiers so upgrades keep accounts, preferences, and saved computers connected. Renaming the display brand does not require a data migration; do not rename those identifiers without one.

The mark is a rounded B with two connected conversation loops and a lime connection point. Keep it simple at small sizes. The app icon lives in `frontend/public/favicon.svg`, the React mark and wordmark in `frontend/src/components/shared/Brand.tsx`, and the README lockup in `docs/assets/band-bots-brand.svg`. Keep their geometry in sync when editing the mark.

Use olive (`#465638`) for the mark and light-mode primary actions, pale olive for selected surfaces, and lime (`#C5E68A`) sparingly. Dark-mode colours use the semantic tokens in `frontend/src/app.css`. Geist is the application typeface. Preserve the colourful agent characters as individual teammate identities.

Light mode is the initial presentation; saved theme preferences take precedence. Keep ordinary workspace surfaces quiet so task progress, approval requests, and finished work remain easy to find. Starter cards draft messages without sending them. Task cards reflect server state and retain the existing cancellation, resume, approval, and computer controls.
